Developer Learning Guide

Spring Kafka Repository Study Path

A practical, step-by-step guide to tracing a message from your application into Kafka, and then from Kafka back into your application.

Recommended starting point: Study Topics 1–4 first to understand a basic producer and consumer. The later topics cover reliability and specialized features.

1. Get a Working Example

Open samples and find a small producer/consumer example. Trace how it configures Kafka and sends or receives a message.

Then read the Spring Kafka Quick Tour for the simplest end-to-end setup. The sample shows code in context; the tour explains the basic setup.

2. Configuration and Factories

These classes create the Kafka clients that Spring Kafka uses:

  • core/ProducerFactory.java and core/DefaultKafkaProducerFactory.java
  • core/ConsumerFactory.java and core/DefaultKafkaConsumerFactory.java
  • config/ConcurrentKafkaListenerContainerFactory.java
  • config/AbstractKafkaListenerContainerFactory.java

Focus on how factories hold Kafka client settings and supply producers or consumers. The listener container factory bridges consumer configuration and the listener that handles messages.

3. Sending Messages

Start in core/:

  • KafkaTemplate.java — the main API application code uses to send records.
  • KafkaOperations.java — the interface for sending operations.
  • ProducerFactory.java and DefaultKafkaProducerFactory.java — how the template gets Kafka producers.

Follow a send call from KafkaTemplate toward the producer factory. You do not need to read every method; begin with the send(...) methods and how they handle the result.

4. Receiving Messages with @KafkaListener

For the consumer path, focus on these classes:

  • annotation/KafkaListener.java — the annotation you put on your method.
  • annotation/KafkaListenerAnnotationBeanPostProcessor.java — finds that annotation and registers a listener endpoint.
  • config/MethodKafkaListenerEndpoint.java — represents a method-based listener.
  • config/ConcurrentKafkaListenerContainerFactory.java — creates the listener container.
  • listener/KafkaMessageListenerContainer.java and listener/ConcurrentMessageListenerContainer.java — run the consumers and deliver records.
  • listener/adapter/MessagingMessageListenerAdapter.java — adapts Kafka records to the method arguments your listener expects.

The core consumer loop is in listener/; the annotation package mostly handles configuration and registration.

5. Serialization and Message Conversion

This determines how Java values become Kafka bytes and back:

  • support/serializer/ — Spring Kafka serializer and deserializer support.
  • support/converter/ — converts between Kafka records and Spring Message objects.
  • listener/adapter/ — shows how converted messages reach listener method arguments.

Study this after you understand sending and receiving, since conversion sits between those operations and your application code.

6. Errors, Retries, and Dead-Letter Topics

Start with:

  • listener/DefaultErrorHandler.java — common listener error handling.
  • annotation/RetryableTopic.java and annotation/RetryableTopicAnnotationProcessor.java — annotation-driven retry topics.
  • retrytopic/ — retry-topic configuration and support.
  • annotation/DltHandler.java — marks a dead-letter-topic handler method.

Learn the ordinary error-handler flow first. Then study retry topics and dead-letter-topic (DLT) handling as a separate strategy.

References: Handling Exceptions and Retry Topics.

7. Testing Your Integration

Open spring-kafka-test/src:

  • EmbeddedKafkaBroker and related embedded Kafka classes — run tests against a broker started for testing.
  • KafkaTestUtils — helpers for test setup and assertions.
  • spring-kafka/src/test — tests alongside the main implementation, useful for seeing expected behavior and edge cases.

Look for tests of the class or feature you are studying. They often show how it is intended to be configured.

8. Optional Features for Later

Once basic send/receive works, explore these if your project needs them:

  • Transactions: transaction/, KafkaTemplate, and DefaultKafkaProducerFactory.
  • Request/reply: requestreply/.
  • Kafka Streams: streams/ and annotation/KafkaStreamsDefaultConfiguration.java.
  • Security: security/jaas/.
  • Micrometer and observation: support/micrometer/.

Suggested Study Order

Sample → factories → KafkaTemplate → @KafkaListener registration → listener container → serialization → error handling → tests

For each topic, follow one path through the code and its tests instead of trying to read the whole module. Start with the Spring Kafka sending and receiving reference alongside the source.

The exact setup can depend on whether your project uses Spring Boot and which versions it runs, so choose a sample that matches your stack.
